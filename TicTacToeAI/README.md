# Tic Tac Toe AI

- Human vs Computer
- Minimax AI Algorithm
- Unbeatable Computer Player
- Win Detection
- Draw Detection
- Input Validation

## Technologies Used

- Python
- Minimax Algorithm
- Game Theory

## How to Run

python tic_tac_toe.py
