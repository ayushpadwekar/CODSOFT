# Rule-Based Chatbot

## Description
A simple chatbot developed using Python that responds to user inputs using predefined rules and pattern matching.

## Features
- Greeting responses
- Time and date responses
- Motivation messages
- AI and Python information
- Continuous conversation
- Exit command

## Technologies Used
- Python
- If-Else Statements
- Pattern Matching
- Loops

## How to Run

python chatbot.py
