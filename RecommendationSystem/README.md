# Movie Recommendation System

## About Project

This is a simple Movie Recommendation System developed using Python. The program recommends movies to users based on the genre they select. It is a basic recommendation system that uses predefined movie data and user preferences to suggest movies.

This project was developed as part of the CodSoft Artificial Intelligence Internship.

---

## Features

- Recommend movies based on genre
- Multiple genres available
- User-friendly menu
- Accepts both genre names and numbers
- Allows multiple recommendations in one run
- Simple and easy to understand

---

## Genres Available

1. Action
2. Comedy
3. Sci-Fi
4. Horror
5. Romance

---

## Technologies Used

- Python
- Dictionary Data Structure
- Loops
- Conditional Statements

---

## How It Works

1. User selects a genre.
2. The program checks the selected genre.
3. Movies related to that genre are displayed.
4. User can continue getting recommendations or exit the program.
